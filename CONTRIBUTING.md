# Contributing

This project is part of the
[E156 micro-paper portfolio](https://github.com/mahmood726-cyber/e156).

## Quick start

```bash
git clone <repo-url>
cd <repo-name>
make install
make test
```

`make install` pulls deps + installs pre-commit hooks. `make help`
lists the rest.
